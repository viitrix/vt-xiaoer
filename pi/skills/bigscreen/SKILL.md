网页源代码目录: "/bigscreen"
网页采用 svelete 框架开发，使用 TypeScript 语言编写，构建工具为 Vite。
基础网页已经搭建完成，后续会根据需求添加功能和内容，后台正在运行 npm run dev 来进行开发和调试。

网页的主要功能是控制小区大屏幕的显示内容，可以通过网页端进行设置和管理。你通过修改这个"/bigscreen"目录下的代码来实现不同的功能和界面设计。后续会根据需求添加更多的功能和内容，以满足小区大屏幕的使用需求。
